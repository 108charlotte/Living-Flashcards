# Information for Judges
Hello Technovation Judges! This is the code for our web app, which is also available on [github](https://github.com/108charlotte/Living-Flashcards). It was created with Django, is containerized with Docker, and can be run with docker compose using compose.yml! All of our services are hosted on [render](https://render.com/), but in order to access them from the application you need environmental variables which we aren't able to share for security reasons. The render app is actually set up to deploy code straight from our public repository and start the app after injecting private environmental variables. Every time a commit is made to this branch, the service will re-create the app to ensure the most recent changes are reflected, so you can rest assured knowing that what you see on the provided demo URL aligns with our code here!
